# Frozen evidence

Each directory is the artifact a closed loop was scored against, written once by its `capture:*` or
`benchmark:*` script and never regenerated by CI or by `pnpm gates` (a gate that rewrote its own
evidence would destroy the thing it protects — `test:capture-immutability` forbids `test:` scripts
from writing here, and pins every one of these directories as frozen).

The newer review packages carry `reviewerType: non_human_independent` with human validation
explicitly deferred until pre-release; the earliest ones predate those fields. Nothing here has been
human-validated yet, and nothing claims to be.
