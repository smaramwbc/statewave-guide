# @statewavedev/guide-react

The guide panel, hooks, element registry and theming for React hosts. Mount `StatewaveGuide`, feed it a query engine and (optionally) `useGuideMemory` — the wiring walk-through is [docs/host-integration.md](https://github.com/smaramwbc/statewave-guide/blob/main/docs/host-integration.md), and the reference host is `examples/guide-e2e`.

Part of [Statewave Guide](https://github.com/smaramwbc/statewave-guide). Not yet published to npm —
install by cloning the repository. Apache-2.0.
