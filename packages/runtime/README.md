# @statewavedev/guide-runtime

Runtime evidence for the guide: what exists on the current screen, visible text, behavioural verification, redaction. Deterministic — no vision model. The running interface may lend context; it does not get to rewrite product truth.

Part of [Statewave Guide](https://github.com/smaramwbc/statewave-guide). Not yet published to npm —
install by cloning the repository. Apache-2.0.
